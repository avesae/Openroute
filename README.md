# Openroute — сайт туристического агентства

Быстрый мультиязычный (RU / EN) сайт туристического агентства на **Next.js 16 + TypeScript + Tailwind CSS 4**.
Туры, направления, отзывы и статьи хранятся в обычных файлах в папке `content/`, поэтому их можно добавлять без программиста.

**Что есть на сайте:** главная с быстрым подбором тура, каталог с фильтрами, страницы туров, направлений, горящих туров, «О нас», отзывов, блога и контактов, а также политика обработки персональных данных, согласие и политика cookie. Кроме того: ИИ-ассистент (любой OpenAI-совместимый API), cookie-баннер с выбором категорий, Яндекс Метрика и Яндекс Карты (подключаются только после согласия посетителя), светлая и тёмная тема, Schema.org, sitemap и hreflang.

Сайт подготовлен под требования российского законодательства: 152-ФЗ (персональные данные), 168-ФЗ (русский язык) и запрет зарубежной авторизации. Подробности — в разделе 7.

## 1. Как запустить

Нужен [Node.js](https://nodejs.org) 20.9 или новее.

```bash
npm install
cp .env.example .env.local   # при необходимости заполните ключи
npm run dev                  # http://localhost:3000
```

Другие команды:

| Команда | Что делает |
|---|---|
| `npm run build` | Собирает продакшен-версию и заодно проверяет все файлы в `content/` |
| `npm start` | Запускает собранную версию |
| `npm run lint` | Проверяет код |

## 2. Как добавить новый тур

1. Скопируйте любой файл из `content/tours/`, например `turkey-istanbul-cappadocia.json`.
2. Переименуйте копию. Имя файла может быть любым, а адрес страницы задаёт поле `slug`: только латиница, цифры и дефисы.
3. Заполните поля. Каждый текст указывается на двух языках: `{ "ru": "...", "en": "..." }`.

| Поле | Что это |
|---|---|
| `slug` | Адрес страницы: `/ru/tours/<slug>` |
| `title`, `summary`, `description` | Название, короткое описание для карточки, полное описание |
| `destination` | Страна, совпадает с именем файла в `content/destinations/` (например, `turkey`) |
| `city` | Город или курорт |
| `types` | Типы отдыха: `beach`, `excursion`, `ski`, `individual`, `family`, `romantic`, `adventure` |
| `durationNights` | Количество ночей |
| `priceFrom` | Цена «от» за человека в рублях (валюта задаётся полем `currency`, по умолчанию `RUB`) |
| `popularity` | 0–100, по этому полю сортируется каталог |
| `departures` | Даты вылета: `{ "date": "2027-01-15", "price": 99000, "seatsLeft": 5 }` |
| `hot` | Если указать `{ "oldPrice": 120000, "until": "2026-12-01" }`, тур попадёт в «Горящие туры» |
| `images` | Фото: `{ "src": "...", "alt": { "ru": "...", "en": "..." } }`, первое станет обложкой |
| `itinerary` | Программа по дням |
| `included` / `notIncluded` | Что входит и что не входит в стоимость |
| `hotel` | `name`, `stars`, `meal` (`RO`, `BB`, `HB`, `FB`, `AI`, `UAI`), `description` |
| `location` | Координаты для карты: `{ "lat": 36.86, "lng": 31.05, "zoom": 12 }` |

4. Запустите `npm run build`. Если в файле опечатка или пропущено поле, сборка покажет имя файла и поле с ошибкой.

Тур автоматически появится в каталоге, на странице страны, в sitemap и в базе знаний ИИ-ассистента.

**Новая страна:** скопируйте файл в `content/destinations/`. Если указать `"popular": true`, страна появится на главной.
**Отзывы, FAQ, команда:** `content/reviews.json`, `content/faq.json`, `content/team.json`.
**Статья в блоге:** создайте два файла с одинаковым именем, `content/blog/ru/<имя>.md` и `content/blog/en/<имя>.md`. Сверху файла идёт блок с заголовком, описанием, датой и обложкой (см. примеры), ниже текст в формате Markdown.

## 3. Как поменять контакты и реквизиты

Все контакты и реквизиты оператора персональных данных лежат в одном файле, `content/site.json`:

```json
{
  "phone": "+7 (495) 000-00-00",
  "email": "hello@openroute.example",
  "max": "https://max.ru/...",        // ссылка на чат или канал в MAX
  "telegram": "openroute_travel",     // имя пользователя без @
  "vk": "https://vk.com/openroute",
  "address": { "street": { "ru": "...", "en": "..." }, "postalCode": "...", ... },
  "hours": { "ru": [...], "en": [...] },
  "geo": { "lat": 55.7616, "lng": 37.6094 },   // точка на Яндекс Карте
  "legal": { "operator": { "ru": "ООО «...»", "en": "..." }, "inn": "...", "ogrn": "...", "privacyEmail": "..." }
}
```

Реквизиты из `legal` выводятся в подвале каждой страницы. Те же данные нужно вписать в `content/legal/*.md`.

## 4. Что ещё нужно заполнить

| Где | Что |
|---|---|
| Фото | Сейчас стоят тестовые фото с Unsplash. В коде такие места помечены комментарием `ЗАМЕНИТЕ ФОТО`. Свои фото кладите в `public/images/` и указывайте путь вида `/images/tour.jpg`. Главное фото первого экрана задаётся в `src/app/[locale]/page.tsx` (`HERO_IMAGE`) |
| Лицензии | `messages/ru.json` и `messages/en.json` → `about.guarantees`, места с пометкой `[ЗАПОЛНИТЬ]` |
| Юридические документы | `content/legal/privacy.*.md` (политика), `consent.*.md` (согласие), `cookies.*.md` (cookie). Это шаблоны: замените данные в квадратных скобках и покажите юристу. После правки согласия обновите дату в `src/lib/legal.ts` |
| Тексты интерфейса | `messages/ru.json` и `messages/en.json` |
| Цвета бренда | `src/app/globals.css`, переменные в начале файла |

## 5. Переменные окружения

Все переменные необязательны. Полный список с пояснениями есть в `.env.example`.

| Переменная | Зачем |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | Адрес сайта для canonical, sitemap и Open Graph |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS` | Почта российского сервиса для отправки заявок (например, Яндекс 360: `smtp.yandex.ru`, порт 465, пароль приложения) |
| `LEAD_EMAIL_TO`, `LEAD_EMAIL_FROM` | Куда и от кого приходят заявки. Без SMTP заявки пишутся в лог сервера |
| `AI_API_KEY`, `AI_BASE_URL`, `AI_MODEL` | ИИ-ассистент. Без ключа кнопка чата скрыта. По умолчанию — Polza AI и модель DeepSeek |
| `NEXT_PUBLIC_YM_ID` | Номер счётчика Яндекс Метрики, включается только после согласия на аналитические cookie |

**ИИ-ассистент и 152-ФЗ.** Сообщения посетителей уходят провайдеру модели. Если серверы провайдера за пределами России (как у DeepSeek), это трансграничная передача: её нужно указать в политике и уведомить Роскомнадзор. Проще выбрать модель с серверами в РФ (YandexGPT, GigaChat) или не включать чат. В приветствии чата посетителя просят не писать паспортные данные.

## 6. Как разместить сайт в России

Персональные данные граждан РФ должны записываться в базы на территории России, поэтому боевой сайт размещайте у российского провайдера (Timeweb Cloud, Selectel, Яндекс Облако, Reg.ru и т. п.). Vercel и Netlify подходят только для демо без реальных заявок.

1. Арендуйте VPS с Ubuntu или облачную платформу для Node.js у российского провайдера.
2. Установите Node.js 20.9+, склонируйте репозиторий, выполните `npm ci && npm run build`.
3. Создайте `.env.local` по образцу `.env.example`.
4. Запустите `npm start` через менеджер процессов (pm2 или systemd), перед ним поставьте Nginx и бесплатный сертификат Let’s Encrypt — сайт должен открываться только по HTTPS.
5. Направьте журнал сервера (строки `[consent]` и `[lead]`) в файл с ротацией и храните его не меньше срока обработки данных.
6. Добавьте сайт в Яндекс Вебмастер и отправьте `https://ваш-домен/sitemap.xml`.

## 7. Что сделано для 152-ФЗ и других законов

| Требование | Как выполнено |
|---|---|
| Согласие на обработку ПДн | Галочка в каждой форме, по умолчанию не отмечена; без неё заявка не принимается. Рядом ссылки на отдельный текст согласия и политику |
| Фиксация согласия | Вместе с заявкой сохраняются время, IP, браузер и версия текста согласия |
| Локализация данных | Заявки — через SMTP российской почты, аналитика и карты — Яндекс; шрифты лежат в проекте |
| Политика и реквизиты | Страницы `/privacy`, `/consent`, `/cookies`; оператор, ИНН и ОГРН в подвале |
| Cookie | Баннер с тремя вариантами: принять все, отклонить необязательные, настроить. Метрика и карты не грузятся без согласия |
| Русский язык (168-ФЗ) | Все тексты интерфейса на русском; латиница — только названия брендов, отелей и коды валют |
| Мессенджеры | WhatsApp (заблокирован в РФ), Instagram и Facebook (Meta признана экстремистской) убраны; вместо них MAX, Telegram и VK |
| Авторизация | Входа на сайте нет, поэтому запрет зарубежной авторизации не затрагивается |

Что остаётся за владельцем бизнеса: подать уведомление в Роскомнадзор до запуска, заполнить реквизиты, согласовать документы с юристом, заключить договоры с хостингом и почтой. Название «Openroute» латиницей допустимо, если это зарегистрированный товарный знак.

## Структура проекта

```
content/                 ← контент: туры, страны, отзывы, FAQ, блог, политика
messages/ru.json, en.json ← тексты интерфейса
src/app/[locale]/        ← страницы (/ru/..., /en/...)
src/app/api/chat/        ← ИИ-ассистент
src/actions/lead.ts      ← обработка заявок и журнал согласий (Zod + SMTP)
src/lib/consent.ts       ← согласие на cookie по категориям
src/lib/legal.ts         ← версия текста согласия
src/components/          ← компоненты интерфейса
src/lib/                 ← загрузка контента, SEO, Schema.org, cookie-согласие
src/proxy.ts             ← перенаправление с / на /ru или /en по языку браузера
```
